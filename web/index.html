Pollo Frito

An interpreter for an R-like language — vectors, lists, matrices, functions and control flow — with two interchangeable parsers. This is the original Java Swing app, running unchanged in your browser through CheerpJ, a JVM for WebAssembly.

  • 1. Wait for the window to load (first visit downloads the Java runtime).
  • 2. Pick an example tab, or write code in new: / Add Pestaña.
  • 3. Press Ejecutar JCC or Ejecutar Cup — output appears in the console on the right.

Example programs

Each one is open in its own tab, in this order. Switch tabs, run them, edit them — or start from scratch with Add Pestaña.

    The language

    a = c(1, 2, 3);                 # vectors
a[1][1][1] = 5;
print(1 + a);                   # [6, 3, 4]
l = list(25, "hola", c(1, 2));  # nested lists
m = matrix(c(1, 2, 3, 4), 2, 2);

factorial = function(num) {
  if (num == 0) {
    return 1
  } else {
    return num * factorial(num - 1)
  }
}
print(factorial(5))             # [120]

    Two parsers, one interpreter

    Ejecutar Cup parses with a JFlex lexer and a CUP LALR grammar; Ejecutar JCC uses a hand-written JavaCC LL grammar. Both build the same AST, which a single tree-walking interpreter runs. TS shows the symbol table and Errores the lexical, syntax and semantic errors.

    In the browser

    • Plots (pie, barplot, hist, plot) and the AST image call Graphviz and open files on the desktop, so here they report an error instead.
    • Guardar stores files in the browser's private storage only.
    • Build it from the repository to use every feature: mvn package, then java -jar target/pollo-frito.jar.
